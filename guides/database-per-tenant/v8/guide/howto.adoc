Clone the companion and start from `initial/`:

[source,bash]
----
git clone -b grails8 https://github.com/grails-guides/database-per-tenant.git
cd database-per-tenant/initial
./gradlew test
----

`initial/` is a Grails 8 web starter with multi-tenancy mode, `SessionTenantResolver`, and `audi`/`ford` datasources already configured. You will add domains, services, controllers, views, and tests. To skip ahead, use `complete/`.
