Clone the companion and start from `initial/`:

[source,bash]
----
git clone -b grails8 https://github.com/grails-guides/grails_url_mappings.git
cd grails_url_mappings/initial
./gradlew test
----

`initial/` is a vanilla Grails 8 web starter. You will add controllers, custom URL mappings, and a unit test. To skip ahead, use `complete/`.
