Generate a fresh Apache Grails 8 web application from link:https://grails.apache.org/start/[grails.apache.org/start] with the two features the rest of the guide expects: `postgres` and `testcontainers`. The functional tests use `ContainerGebSpec` from `org.apache.grails:grails-geb`, which runs the browser in a Testcontainers Selenium container - no `geb-with-webdriver-binaries` feature is needed.
