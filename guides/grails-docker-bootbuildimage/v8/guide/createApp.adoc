Generate a fresh Apache Grails 8 web application from link:https://grails.apache.org/start/[grails.apache.org/start] with the three features the rest of the guide expects: `postgres` (the JDBC driver and a Postgres datasource template), `testcontainers` (so we can spin up a real Postgres in functional tests), and `database-migration` (Liquibase, so the production image can run schema changes on first start).
