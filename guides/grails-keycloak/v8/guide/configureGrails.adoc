Add the Spring Security client libraries to `build.gradle`. Grails 8.0.0 manages the Spring Boot 4.1.1 line through `grails-bom`, so these two dependencies do not need their own versions:

[source,groovy]
----
implementation 'org.springframework.boot:spring-boot-starter-security'
implementation 'org.springframework.boot:spring-boot-starter-oauth2-client'
----

`complete/gradle.properties` sets `grailsVersion=8.0.0`. Keep `initial/gradle.properties` on that same version.
