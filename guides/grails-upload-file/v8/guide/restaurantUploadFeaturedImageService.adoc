<1> If validation fails, the upload form is shown again with the errors.
<2> The image bytes and content type are passed to a GORM Data Service.

Add `uploadFeaturedImage: 'POST'` to the controller's `allowedMethods`.

The update method has to check the version that the form was opened with, so you write it yourself. Change `RestaurantDataService` from an interface to an abstract class, make the existing methods `abstract`, and add the update method. GORM still implements the abstract methods for you:

<1> `@Transactional` loads and updates the restaurant in one transaction.
<2> If the restaurant has a higher version than the form sent, someone else saved it after the form was opened. The upload is rejected with the `default.optimistic.locking.failure` message, instead of overwriting the newer image. Assigning the version to the restaurant is not enough, because Hibernate checks the version it loaded from the database, not the value you assign.
