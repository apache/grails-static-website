The AWS SDK finds credentials with its https://docs.aws.amazon.com/sdk-for-java/latest/developer-guide/credentials-chain.html[default credentials provider chain]. Among other places, it looks in:

* The environment variables `AWS_ACCESS_KEY_ID` and `AWS_SECRET_ACCESS_KEY`
* The Java system properties `aws.accessKeyId` and `aws.secretAccessKey`
* The shared credentials file, `~/.aws/credentials`
* The IAM role of the EC2 instance, ECS task, or other AWS service running the application

Never put credentials in `application.yml`. To try the hotel upload against your own bucket, pass the bucket, region, and credentials as environment variables. Spring Boot maps `AWS_S3_BUCKET` and `AWS_S3_REGION` to `aws.s3.bucket` and `aws.s3.region`:

[source, bash]
----
AWS_S3_BUCKET=my-bucket AWS_S3_REGION=eu-west-1 \
AWS_ACCESS_KEY_ID=XXXXX AWS_SECRET_ACCESS_KEY=XXXXX \
./gradlew bootRun
----
