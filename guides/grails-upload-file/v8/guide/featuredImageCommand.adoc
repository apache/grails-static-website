<1> A missing or empty file is rejected.
<2> The file name must end in `.jpg`, `.jpeg`, or `.png`, and the browser must send an `image/jpeg` or `image/png` content type.
<3> `StringUtils.getFilename` keeps only the last segment of the name the browser sent, so `../../etc/evil.png` becomes `evil.png`.
<4> Any character other than letters, digits, dots, underscores, and hyphens is replaced with `_`.

The original file name comes from the browser, so never use it as a path as it is. The services in this guide build file paths and S3 keys from `sanitizedFilename()` instead.

When validation fails, Grails looks up an error message whose code starts with the command object class name and the property name. Without one, the user sees the generic `default.invalid.validator.message`, which includes the `toString()` of the uploaded file. Add clear messages to `messages.properties`:
