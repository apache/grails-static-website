<1> `GrailsConfigurationAware` gives the service the configuration when the application starts.
<2> The point of interest is loaded first. If it does not exist, no file is written.
<3> A random UUID in front of the sanitized file name gives every upload its own file and URL. Uploading a file with the same name again does not overwrite the current image, and browsers do not keep showing a cached copy of the old one.
<4> `transferTo` writes the uploaded file to its path in the folder. The path uses the sanitized file name, so it cannot point outside the folder.
<5> A GORM Data Service updates `featuredImageUrl`.
<6> If the point of interest cannot be updated, or the update throws an exception, the new file is deleted again. The current image is not touched.
<7> After a successful update, the previous image is deleted.
<8> `deleteFileByUrl` finds the file from its URL, and only deletes files inside the folder.
