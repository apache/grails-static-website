<1> The service saves the file and updates the point of interest.

Configure the folder where images are saved, and the root URL they are served from:

[source, yaml]
.grails-app/conf/application.yml
----
grails:
  guides:
    cdnFolder: build/uploads
    cdnRootUrl: /uploads
----

<1> `GrailsConfigurationAware` gives the service the configuration when the application starts.
<2> `transferTo` writes the uploaded file to its path in the folder. The path uses the sanitized file name, so it cannot point outside the folder.
<3> A GORM Data Service updates `featuredImageUrl`.
<4> If the point of interest cannot be updated, the file is deleted again.
