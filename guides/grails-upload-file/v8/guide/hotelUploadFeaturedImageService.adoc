<1> The `S3Client` bean from `resources.groovy` is injected by name.
<2> The bucket name is read from the configuration.
<3> `putObject` streams the uploaded file to S3, with its content type.
<4> The SDK builds the object's URL for the configured region or endpoint.
<5> A GORM Data Service stores the key and URL.
<6> If the hotel cannot be updated, the object is deleted from S3 again.
